## 📈 Stock Portfolio Tracker

A Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Internship Program. The application allows users to manage stock investments, calculate portfolio value, generate portfolio summaries, and export reports in CSV and image formats.

### 🎯 Objective

Build a portfolio management system that:

- Tracks stock holdings and quantities
- Calculates total investment value
- Generates portfolio summaries
- Exports reports as CSV files
- Creates visual portfolio reports as images

---

## 🚀 Features

✅ Add stocks with quantity tracking

✅ Automatic portfolio value calculation

✅ Predefined stock price database

✅ Portfolio summary table

✅ CSV report generation

✅ Portfolio image report generation

✅ Desktop export functionality

✅ Input validation and error handling

✅ Data visualization using Matplotlib

## 📊 How It Works

1. User enters stock symbols and quantities.
2. Application calculates stock values using predefined prices.
3. Portfolio summary is generated automatically.
4. Total investment value is calculated.
5. User can:
   - View portfolio summary
   - Generate image report
   - Export CSV report
6. Reports can be saved directly to the desktop.
